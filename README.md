## Overview

Wonder Cabinet Episode Art Builder provides podcast creators with a straightforward way to produce repeatable episode artwork. Its three-panel workflow lets you place images into separate sections, refine their positioning, and assemble the result as a square composition in the browser.

Because the application is a static site, it does not depend on a server or account. Built-in Unsplash search helps locate images suited to an episode's subject. Once the layout is ready, the tool exports a 3000x3000 composite JPG together with a `credits.md` file for image attribution.

## What You Can Do

- Compose podcast artwork using three dedicated panels
- Drop images directly into the panels
- Look up theme-related imagery through Unsplash search
- Adjust the placement of images inside their panels
- Save the finished composition as a 3000x3000 JPG
- Create a companion `credits.md` attribution file
- Work entirely from a web browser

## Creating Artwork

1. Launch Wonder Cabinet Episode Art Builder in your browser.
2. Create a new composition with three panels.
3. Drag the desired images into the appropriate panels.
4. Search Unsplash for episode-related imagery if additional source material is needed.
5. Move each image within its panel to achieve the desired framing.
6. Export the finished design as a 3000x3000 JPG.
7. Store the generated `credits.md` file together with the exported artwork.

## Frequently Asked Questions

### Is registration necessary?

No. The browser application can be used without an account.

### Does the application run on a server?

No. It operates in the browser and is provided as a static site.

### May I add images from my own collection?

Yes. Bring your own images into the panels by dragging and dropping them.

### Where can I get episode-themed images?

The integrated Unsplash search can be used to find imagery connected to the episode topic.

### Which files are produced during export?

The main output is a 3000x3000 JPG, and the tool also generates a `credits.md` file.

### Can panel images be repositioned?

Yes. Adjust an image's position inside its assigned panel before exporting the composition.

### What can I try if the application is not working?

Make sure JavaScript is enabled, refresh the page, and confirm that the hosted build can be reached. If Unsplash search fails, inspect the browser's network connection.

### How do I get the newest version?

New versions are published through the static deployment. Open the [latest build](https://chris-cooperbpls138.github.io/wonder-cabinet-episode-art/) to use the currently hosted release.
